# Improved real-sensor evidence

This folder contains the terminal complete improved-sensor campaign and its independent audit. Raw attempt shards preserve exact JSON bytes; their manifest and companion hash map identify every member. The source archive comes from the frozen Git revision recorded in code_revision.json. Local analysis helpers, development search, numerical-stability search, preflight and pilot receipts remain separately available. The original completed 100-attempt run failed its strict trajectory audit and is preserved in explicitly rejected archives with its frozen source; it is excluded from all accepted performance claims.

The executed report lives in examples/improved_sensor_benchmark.ipynb; its portable HTML and plot exports are added after rendering. SHA256SUMS covers the final files after that step. No raw feature arrays, model weights, credentials or machine-specific home paths are intentionally included.

These are ideal CPU results for eight independent two-qubit patches. Supervised LDA is a classical part of the learning recipe. The fixed held-out rows come from the same nine official test subjects used previously. The numerical repair retests the same already evaluated holdout, not an independent external cohort.
